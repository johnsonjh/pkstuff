The following items are new, changed, or fixed from version 1.50
of PKLITE in this release, version 2.01:


- Added the ability to compress Windows 16-bit (.EXE and .DLL)
  program files.
  ***NOTE THAT WINDOWS FILES COMPRESSED WITH PKLITE CAN NOT BE
     DECOMPRESSED.***

- Added the detection of Windows resources (icons, dialog boxes and other
  bitmaps) so they can be compressed.

- Added the automatic detection of a Windows or DOS .EXE program file.

- Corrected a bug with the checksum option for DOS files.

- Corrected problems with compression of DOS .SYS device drivers.

- Allows for compression of read-only files to an output file.

- Corrected bug with uncompressing EXEPACK files before compression
  with PKLITE.

- Shows the overall compression achieved when compressing multiple
  files.

- Corrected the problem with OS/2 loading files above 64K after
  being compressed with PKLITE.
